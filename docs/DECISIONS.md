# DECISIONS.md

Решения, принятые в ходе разработки.

---

## 2026-08-12: Структура проекта
- **Контекст**: Требуется SPA внутри единственного маршрута `/` (ограничение sandbox).
- **Решение**: Вся навигация реализована через zustand-стор `routerStore` с паттерном клиентского роутинга. Компоненты монтируются/размонтируются на основе текущего «роута» в сторе.
- **Альтернативы**: next/link с реальными роутами (невозможно из-за ограничения sandbox).
- **Статус**: OK

---

## 2026-08-12: PWA Service Worker
- **Контекст**: Serwist требует сложной конфигурации с Next 16 и может быть нестабилен в данном окружении.
- **Решение**: Используем кастомный service worker в `public/sw.js` с CacheFirst для статики и NetworkFirst для API. Регистрация SW из клиентского компонента.
- **Альтернативы**: Serwist (@serwist/next), next-pwa.
- **Статус**: OK

---

## 2026-08-12: Шрифт Onest (self-hosted)
- **Контекст**: Приложение должно работать офлайн, Google Fonts не подходят.
- **Решение**: Используем `@fontsource/onest` для self-hosted шрифта. Подключаем через CSS import в layout.
- **Альтернативы**: Google Fonts через next/font (не работает офлайн), локальный @font-face.
- **Статус**: OK

---

## 2026-08-12: Локальное хранилище
- **Контекст**: Нужен офлайн-first storage для дневника, сессий, ачивок.
- **Решение**: `idb-keyval` как лёгкая обёртка над IndexedDB. Zustand-стор с middleware persist через кастомный storage adapter.
- **Альтернативы**: Dexie (тяжелее), localStorage (ограничение 5MB).
- **Статус**: OK

---

## 2026-08-12: Оплата YooKassa
- **Контекст**: `@yookassa/sdk-web` может быть недоступен для установки в текущем окружении.
- **Решение**: Создаём абстракцию `usePayment` hook с заглушками для реальной интеграции. При реальном деплое подключаем SDK.
- **Альтернативы**: Полная интеграция SDK сейчас (рискованно), stripe (не поддерживает СБП).
- **Статус**: REVIEW — требуется реальное подключение YooKassa при продакшн-деплое.

## 2026-08-12: ZHeader — единая точка рендеринга
- **Контекст**: Feature-компоненты импортировали свой ZHeader, что создавало дубликаты.
- **Решение**: Router в page.tsx рендерит ZHeader для всех роутов (кроме home). Feature-компоненты для основных экранов не рендерят свой заголовок. Компоненты с showHeader=false (wizard, breathing, grounding) рендерят свой собственный.
- **Статус**: OK

## 2026-08-12: Toast контекст

## 2026-08-21: Узоры мыслей в дневнике
- **Контекст**: Библиотека узоров мышления (18 КПТ-паттернов) была мёртвым кодом — в wizard использовался только выбор эмоции. Продукт переименован в «Дневник эмоций», но суть должна сохранить работу с узорами мышления (КПТ).
- **Решение**: В шаге B wizard (после выбора эмоции) добавлен ThoughtPatternSelector «Похоже на один из узоров мышления?». При выборе узора на шаге E показываются описание, пример и вопросы для рефрейминга. Узор сохраняется в записи (patternId/patternName) и отображается в истории. Выбор узора опционален.
- **Альтернативы**: Заменить эмоции узорами целиком (потеря эмоциональной валидации), удалить библиотеку (потеря обучающего компонента КПТ).
- **Статус**: OK

## 2026-08-21: Серверная валидация подписки
- **Контекст**: Оплата была полностью клиентской (IndexedDB) и легко подделывалась. Нужен реальный продукт с env-конфигурацией.
- **Решение**: Серверный слой: SQLite через встроенный `node:sqlite` (ноль зависимостей, Node 24), таблица subscriptions. API: `GET /api/entitlement`, `POST /api/payments` (создание платежа YooKassa), `POST /api/payments/trial`, `POST /api/payments/webhook`. Клиент больше не может сам активировать premium — только сервер. Без ключей YooKassa работает dev-режим (мгновенная активация для теста флоу). Триал — один раз на deviceId, grace-период 3 дня.
- **Альтернативы**: Prisma+Postgres (тяжело для МВП), внешняя платежная подписка-сервис (нет доступа).
- **Статус**: OK. REVIEW: проверка подписи вебхука упрощена (HMAC-SHA256 от body+secret, если задан YOOKASSA_WEBHOOK_SECRET); ручной перевод требует ручной активации администратором; deviceId — анонимная идентификация без аккаунтов.

- **Контекст**: Блок 8 требовал E2E, но тестов не было.

- **Альтернативы**: Cypress (тяжелее), только unit.
- **Статус**: OK

## 2026-08-21: Офлайн-фолбэк
- **Контекст**: SW отдавал закэшированный `/` при офлайн-навигации, отдельной fallback-страницы не было.

- **Статус**: OK
